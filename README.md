# Da Sigma Squads Optimizer KBF

Windows 11 gaming optimizer: profiles your hardware, recommends machine-specific performance tweaks, applies them with full backup + revert, and proves the result with before/after benchmarks.

Tauri 2 (Rust + React/TypeScript) GUI around a PowerShell tweak engine. Runs elevated; Windows 11 only.

See `CLAUDE.md` for the full spec and build phases.

## Dev (CMD, elevated terminal)

```
npm install
npm run tauri dev
```
